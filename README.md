# 非遗跨境展演知识边界

本项目用于整理非遗跨境展演知识边界领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号。

## 目录

- `src/`：事件种类、最小字段校验与授权包服务实现。
- `data/sample.json`：用于核对资料格式的虚构事件。
- `tests/`：保证样例与领域约定保持一致，并覆盖授权包服务规则。

## 本地核对

```bash
npm test
```

## 本地运行

测试命令：

```bash
npm test
```

编译或构建命令：

```bash
npm run build
```

所有测试和构建均在单个 Linux 应用容器内完成，不需要另行启动数据库或外部服务。

## 授权包服务

`src/licensing_package_service.js` 在事件日志之上实现授权包领域逻辑（`LicensingPackageService`），可由历史事件整体重放恢复。

### 事件词汇

| 事件种类 | 含义 |
| --- | --- |
| `KNOWLEDGE_REGISTERED` | 知识单元登记（权利人、公开层级、地域、用途、有效期） |
| `SOURCE_VERSION_REGISTERED` | 原文版本登记（版本标识与内容摘要） |
| `TRANSLATION_REVIEWED` | 译文译审，必须引用已登记的确定原文版本 |
| `HOLDER_CONSENT_RECORDED` | 权利人同意/反对意见 |
| `LICENSE_DECIDED` | 授权决定（机构、地域、用途、有效期） |
| `KNOWLEDGE_UNIT_FROZEN` / `KNOWLEDGE_UNIT_UNFROZEN` | 权利人意见不一致时冻结单元，重新一致后解冻 |
| `PACKAGE_ISSUED` | 发包，载荷为机构当前获准的最小集合及内容摘要 |
| `USE_ACKNOWLEDGED` | 离线使用回执或下载回执 |
| `SUBLICENSE_REQUESTED` | 转授权申请 |
| `PERMISSION_WITHDRAWN` | 紧急停用/撤回，同一单元+机构的通知版本递增 |
| `WITHDRAWAL_ACKNOWLEDGED` | 撤回通知的接收确认 |
| `INSTITUTION_EXITED` | 机构退出 |

### 核心规则

- **最小集合发包**：`issuePackage` 只纳入接收机构当前有效、单元未冻结、且已登记原文版本的授权，并携带与最新原文版本对应的已审译文。包内容做规范化摘要，同一 `package_id` 内容不同时报 `PACKAGE_CONTENT_CONFLICT`，完全相同的重复签发按稳定标识归并。
- **意见不一致冻结**：同一单元权利人同时出现同意与反对时仅冻结该单元，其他单元照常发包；意见重新一致后自动解冻。
- **版本化撤回与留痕**：撤回产生版本递增的新通知（支持指定机构或全量），授权状态置为 `withdrawn`，但历史发包、回执事件不删除。
- **稳定标识归并**：离线回执、重复下载、转授权申请、撤回确认均以稳定标识归并，同标识异内容一律冲突。
- **机构退出**：退出后立即拒绝发包、下载、转授权与新授权决定；迟到的离线回执作为历史展演事实继续登记。
- **恢复补送**：`recover()` 不产生事件、不重复签发能力，只列出尚无确认的撤回通知供补送。
- **审计反查**：`auditTrace(receipt_id)` 从一次实际使用反查知识单元、原文版本、译审记录、授权决定与该包的全部接收回执。
